LangChain-based Robot Task Planning with Vision-Language and RAG Extensions"

该项目开发了一种智能机器人助手，该助手使用LangChain框架将自然语言指令转换为可执行的机器人动作。学生将基本的机器人能力——包括感知、导航、操控和交互——作为模块化的LangChain工具来实现，并设计一个核心代理，能够根据用户命令规划、执行和监控多步任务。

框架强调模块化和灵活性。可能的扩展包括将视觉语言模型（VLM）集成到环境推理中，将检索增强生成（RAG）集成到知识增强操作中，使代理能够通过闭环反馈检测和纠正执行失败的错误恢复机制，以及其他可能的集成。
学生们在构建由大型语言模型驱动的适应性认知服务机器人方面获得了实践经验。

This project develops an intelligent robotic assistant that converts natural-language instructions into executable robot actions using the LangChain framework. Students implement fundamental robot capabilities – including perception, navigation, manipulation, and interaction – as modular LangChain tools, and design a core agent capable of planning, executing, and monitoring multi-step tasks from user commands.

The framework emphasizes modularity and flexibility. Possible extensions include integrating Vision-Language Models (VLM) for environmental reasoning, Retrieval-Augmented Generation (RAG) for knowledge-enhanced operations, error recovery mechanisms that enable the agent to detect and correct execution failures through closed-loop feedback, and other possible integration.

Students gain hands-on experience in building adaptive, cognitive service robots powered by large language models.
