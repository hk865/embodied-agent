# 规划控制（Planning & Control）
> 核心职责：根据环境信息与任务目标，**生成**可行的路径/轨迹（为运动控制层提供 setpoint / reference）。

---

## 1. 地图导航

### 1.0 地图基础表示与代价地图

**地图基础表示**
- 2D 栅格地图（Occupancy Grid）— 离散化占据概率，用于室内移动机器人
- 3D 体素（Voxel Grid）— 3D 版本栅格，适用于无人机/机械臂
- 点云（Point Cloud）— 原始传感器数据，需配准与滤波
- Mesh 网格 — 表面建模，适用于图形学+仿真
- 八叉树（OctoMap）— 分层体素，稀疏高效存储 3D 环境
- 3D+语义地图 — 标注物体类别/属性，支持人机交互 & 语义导航

**代价地图（Costmap）**
- Global costmap — 基于全局地图，用于全局规划
- Local costmap — 实时更新的滑动窗口，用于局部避障
- 分层结构：static layer / obstacle layer / inflation layer
- Inflation（膨胀层）：将障碍物扩展一定半径，保证安全距离

**主要库/API**
- ROS nav2：`nav2_costmap_2d`, `nav2_map_server`
- Google Cartographer — 实时 SLAM + 栅格建图
- OctoMap / octomap_server — 3D 八叉树建图
- Open3D / PCL — 点云处理与可视化
- grid_map — 多层级栅格地图（ETH Zurich）

### 1.1 全局规划（Global Planning）
> 已知全局地图，离线计算从起点到终点的最优路径。

| 算法 | 特点 | 适用场景 |
|------|------|----------|
| Dijkstra | 无启发式，保证最优，速度慢 | 小规模离线路径 |
| A* | 启发式搜索，保证最优（启发可接受时） | 最广泛使用的全局规划器 |
| Jump Point Search (JPS) | A* 的优化变体，跳过对称节点 | 均匀栅格，大幅加速 |
| Theta* | 任意角度路径，无格点限制 | 更短更平滑的路径 |
| RRT / RRT* | 基于采样，高维适用 | 非完整约束，高维空间 |
| PRM (Probabilistic Roadmap) | 离线建图，在线查询 | 静态环境多次查询 |

**特殊场景**
- 未知/部分已知环境 → 探索式规划（Frontier-based Exploration）
- 全覆盖路径规划（Coverage Path Planning）→ 扫地机器人、农业巡检
- 势场法（Potential Field）→ 同时导航+避障，但易陷入局部极小值

### 1.2 局部规划（Local Planning）
> 动态环境中的实时规划，通常以滚动窗口方式运行。

| 算法 | 特点 |
|------|------|
| DWA (Dynamic Window Approach) | 速度空间采样，考虑运动学约束 |
| TEB (Timed Elastic Band) | 时空轨迹优化，支持动态障碍 |
| MPC for Planning | 模型预测控制用于轨迹规划 |
| Pure Pursuit | 几何追踪，适合阿克曼转向 |
| Stanley Controller | 前轮转角+横向误差，自动驾驶常用 |
| 人工势场法 | 引力+斥力实时避障 |

**关键概念**
- 前瞻距离（Lookahead Distance）— 决定追踪多远的目标点
- 规划频率 — 通常 10~50 Hz，需与感知和控制的频率匹配
- 安全边界 — 对动态障碍物预留的安全距离

### 1.3 轨迹生成与平滑
> 路径（几何无时间） → 轨迹（几何+时间）。

- 多项式轨迹：Minimum Snap / Minimum Jerk
- B-Spline / Bezier 曲线平滑
- 梯形速度规划（Trapezoidal Velocity Profile）
- 时间最优参数化（TOPP：Time-Optimal Path Parameterization）

## 2. 机器人/机械臂路径规划

### 2.1 问题建模
- **配置空间（C-space）**：所有可能关节角度的集合
- **C-obstacle**：障碍物在 C-space 中的映射
- **自由空间（C-free）**：C-space 中无碰撞的区域
- 维度：6-DOF 机械臂有 6 维 C-space；人形机器人可达 30+

### 2.2 基于采样的规划（Sampling-based）
| 算法 | 特点 | 适用 |
|------|------|------|
| RRT | 快速探索随机树，单次查询 | 高维实时规划 |
| RRT* | RRT + 渐进最优性 | 离线/准离线 |
| RRT-Connect | 两端生长+贪婪连接 | 提速 |
| Informed RRT* | 椭圆采样域聚焦 | 进一步提速 |
| PRM | 构建路线图，多次查询 | 静态环境 |
| PRM* | PRM + 渐进最优 | 静态多次查询 |

### 2.3 基于优化的规划（Optimization-based）
| 算法 | 特点 |
|------|------|
| CHOMP | 协变梯度优化，考虑碰撞代价 |
| STOMP | 随机轨迹优化，无需梯度 |
| TrajOpt | 序列凸优化，SQP 求解 |
| GPMP2 | 高斯过程运动规划，概率框架 |

### 2.4 运动学与逆运动学（Kinematics & IK）
- 正运动学（FK）：关节角度 → 末端位姿
- 逆运动学（IK）：末端位姿 → 关节角度（多解 / 无解）
- 常用库：KDL (Orocos)、Trac-IK、ikfast
- 数值解 vs 解析解

### 2.5 约束处理
- 避碰约束（Self-collision & Environment-collision）
- 关节限位（Joint Limits）
- 速度/加速度/加加速度约束
- 末端姿态约束（如端水杯不能倾斜）

## 3. 决策与行为规划（Decision & Behavior Planning）

- 分层架构：Mission → Task → Behavior → Motion
- 有限状态机（FSM）：简单直接，状态爆炸问题
- 行为树（Behavior Tree）：模块化、可复用，ROS2 默认
- 决策算法：MDP / POMDP 用于不确定性环境

---

## 4. 算法总览 & 评估

### 4.1 算法分类
| 分类维度 | 类型 |
|----------|------|
| 确定性 | 完备（Complete） → 分辨率完备（Resolution-complete） → 概率完备（Probabilistically-complete） |
| 方法 | 基于搜索 / 基于采样 / 基于优化 / 基于学习 |

### 4.2 评估指标
- 路径长度、规划时间、成功率
- 平滑度（曲率、jerk）
- 离障碍物最小距离（Clearance）
- 可执行性（是否满足运动学/动力学约束）

### 4.3 仿真与可视化
- Gazebo / Isaac Sim / MuJoCo — 物理仿真
- RViz / Foxglove — 可视化
- MoveIt — 机械臂规划框架
- Navigation2 — 移动机器人规划框架
- OMPL — 通用规划算法库

## 5. 与运动控制的关系

```
任务层 → 决策层 → 规划层（本文件） → 运动控制层 → 执行器
                    ↓                        ↓
              生成 reference           跟踪/趋近 reference
              (path/trajectory)        (PID/LQR/MPC/WBC)
```

规划控制输出**参考轨迹**（空间+时间），运动控制负责**跟踪执行**。
- 规划回答：怎么走？
- 控制回答：怎么让电机照着走？
