# 像素与视频生成式世界模型

## 1. 任务与资格

这条路线学习：

\[
p(o_{t+1:t+H}\mid o_{\le t}, a_{t:t+H}, c)
\]

输出可以是 RGB 帧、视频 latent 或离散视频 token。没有动作时是观察预测/生成世界；加入动作、相机轨迹或控制 token 后，才开始具备交互式世界模型资格。

## 2. 输入输出与数据

- 输入：历史视频、文本、相机位姿、键鼠/车辆/机器人动作，可选深度和分割。
- 输出：未来帧、video latent、可选深度/flow/segmentation。
- 数据：互联网视频适合预训练；具身后训练必须有严格对齐的 `(history, action, future)`；多视角要有同步与标定。

最小样本为 4—16 帧 context、未来动作 chunk 与 8—32 帧 target。相机 ego-motion 必须与对象运动区分，否则模型会把镜头移动学成物体物理。

## 3. Base 与最小 Baseline

| 组件 | 最小版本 | 扩展版本 |
|---|---|---|
| tokenizer | 视频 VAE / latent encoder | 共享多视角或 3D-aware tokenizer |
| dynamics | AR Transformer 或 DiT | 分层时空 Transformer / MoT |
| condition | action MLP + text encoder | action token、轨迹控制、对象控制 |
| decoder | latent diffusion decoder | 多头 RGB/depth/flow decoder |

最小 Baseline：同一 video Base 上的 `action-off`、`action-on`、`action-shuffled`；三者在未来动作不同的状态上必须可区分。

## 4. 架构与损失

可采用 AR token 交叉熵、扩散去噪或 flow matching。行动条件可以进入 cross-attention、time-aligned token stream 或 AdaLN。核心不是“把 action 拼到 prompt”，而是确保每个未来时间位置能访问其对应动作和坐标含义。

\[
\mathcal L = \mathcal L_{video}+\lambda_a\mathcal L_{action\text{-}sensitivity}+\lambda_t\mathcal L_{temporal}
\]

其中 `action-sensitivity` 可用配对动作造成的 target feature 差异来约束，避免条件被忽略。

## 5. 推理与规划

- **Renderer**：给人看未来或产生内容；关注观感、可控性和速度。
- **Data engine**：生成天气、布局、视角或罕见事件变体；需防范 synthetic bias。
- **Model predictive control**：对候选动作生成多个未来，用 goal/value/verifier 评分；成本常是主要瓶颈。

## 6. 评测

视觉：FVD/LPIPS/人评；时序：flow/对象漂移；动作：动作打乱、轨迹跟随、失败动作；长时：重访一致性和自由 rollout 崩坏时刻；规划：候选排序与真实成功率。

## 7. 相对 Baseline 的典型创新

- 更好的 video tokenizer 或扩散/flow backbone：主要改善视觉世界先验。
- 加入 action、camera、文本或结构化控制：主要改善可控性。
- memory、causal attention、forcing/distillation：主要改善长时一致性或速度。
- 输出 depth/flow/segmentation：主要增加可检验结构，不自动等于物理理解。

## 8. 边界与失败模式

- 视频逼真可由纹理和运动先验产生，未必有正确接触、质量或因果。
- free-running 中错误会自回归放大；固定 clip 结果不能外推到交互数分钟。
- 高质量视觉 decoder 常使在线规划过慢；可训练时保留 decoder、推理时使用 latent scorer，但需独立证明。
