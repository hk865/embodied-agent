# 对象与结构化状态世界模型

## 1. 任务与资格

对象/状态路线将世界表示为可命名的实体、属性、关系和动态变量：

\[
z_t=\{(id_i, class_i, pose_i, vel_i, attr_i)\}_{i=1}^{N_t},\qquad
z_{t+1}=f_\theta(z_t,a_t,c)
\]

它适合需要解释、任务规划、接触关系、资产复用或低带宽记忆的系统。结构化不必等于人工标注，也可由 object slot、scene graph 或 occupancy token 获得。

## 2. 输入输出与数据

- 输入：图像/点云、相机位姿、动作、可选检测/分割/语言。
- 输出：对象状态、关系图、轨迹、接触/affordance、可选渲染或未来视频。
- 数据：真实数据需要 tracking、校准与对象关联；仿真可提供 pose、instance、contact 等强监督。

对象的 `id`、坐标系、出生/消失规则和遮挡状态必须写进 Schema，否则“身份保持”不可测。

## 3. Base 与最小 Baseline

| 部件 | 最小实现 | 对照 |
|---|---|---|
| 感知 | detector/segmenter + tracker | dense latent / 无 object id |
| state | slot attention 或 object table | 单向量 latent |
| dynamics | GNN / Transformer / neural ODE | 独立对象、无关系边 |
| renderer | object-conditioned decoder | 无 renderer 的 planning-only |

## 4. 训练与损失

\[
\mathcal L_{state}=\mathcal L_{assoc}+\lambda_p\|\hat p-p\|+\lambda_v\|\hat v-v\|+\lambda_r\mathcal L_{relation}
\]

可用 set matching / Hungarian loss 处理对象顺序不定；动作接触可额外预测 `contact(i,j,t)`。如果只依赖伪标签，应报告伪标签噪声和可靠性 mask。

## 5. 推理与规划

对象状态便于：检索“红杯在哪里”、判断可达性、建立语言 grounding、以关系作为 planner 状态、将长期记忆压缩为事件日志。也可与视频模型互补：结构化 state 负责事实与约束，视频 decoder 负责外观。

## 6. 评测

- detection/association：MOTA、IDF1、object permanence；
- 动态：位置/速度/关系误差及碰撞、接触分类；
- 因果：对象级状态变化是否跟随动作；
- 规划：对象目标任务成功、语言 referring accuracy；
- 长时：重访时 ID、状态和关系恢复。

## 7. 典型创新

- object slot / graph：改变状态的可分解性；
- relation / contact head：加入交互结构；
- language grounding：把对象状态接入任务语义；
- state-video joint：让结构化状态获得视觉监督与可审计输出。

## 8. 边界与失败模式

- 开放世界对象数可变、遮挡、反光、透明和软体使稳定 objectization 困难；
- 错误检测会在 dynamics 中长期传播；
- 结构化标签昂贵，伪标签会形成自证循环；
- 显式对象不等于获得材料、摩擦或接触动力学。
