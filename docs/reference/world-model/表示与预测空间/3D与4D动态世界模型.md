# 3D 与 4D 动态世界模型

## 1. 任务与资格

3D/4D 路线以空间结构作为共享状态，目标是跨相机和时间预测：

\[
z_t^{3D}=\{\text{occupancy},\text{radiance/GS},\text{objects},\text{poses}\},\qquad
z_{t+1}^{3D}=f_\theta(z_t^{3D},a_t)
\]

4D 不是“更多帧”，而是 3D 空间加时间演化和对象动态。它解决多视角、重访、几何可计算性问题，但不天然解决物理。

## 2. 输入输出与数据

- 输入：多视角 RGB/RGB-D、相机轨迹、LiDAR/点云、动作、可选语义与对象位姿。
- 表示：BEV、voxel/occupancy、point cloud、NeRF、3DGS、mesh、object-centric 4D scene。
- 输出：未来 occupancy、对象姿态、渲染视图、depth/flow、collision proxy。

严格记录相机内外参、时间同步和单位。单目视频可产生弱几何先验，但不应与有真值多传感器几何评测混为一谈。

## 3. Base 与最小 Baseline

| 目的 | 最小 Baseline | 关键对照 |
|---|---|---|
| 自动驾驶 | BEV/occupancy encoder + latent dynamics | 2D camera-only |
| 机器人台面 | RGB-D object map + GNN dynamics | 2D latent + memory |
| 空间生成 | 3DGS/mesh + render | 无结构 video generation |
| 动态重建 | 4D Gaussian / scene flow | 静态 map + moving mask |

## 4. 训练与损失

\[
\mathcal L_{3D}=\lambda_o\mathcal L_{occ}+\lambda_d\mathcal L_{depth}+\lambda_p\mathcal L_{pose}+\lambda_v\mathcal L_{view}+\lambda_{dyn}\mathcal L_{transition}
\]

多视角 photometric loss 对外观有帮助；occupancy、pose、scene flow、对象状态和 contact/constraint loss 才使结构可用于动态预测。只优化 novel-view synthesis 时，应明确它是 renderer/reconstruction 任务。

## 5. 推理与规划

3D 状态可作为 SLAM 地图、碰撞检测、视角规划、空间检索和长时记忆；动作世界模型还需从 3D state rollout 未来占据、对象位姿和可行性。实用系统常把几何模块、物理引擎和学习 dynamics 混合，而非要求一个模型承担所有物理。

## 6. 评测

- 几何：ATE/RPE、depth AbsRel、Chamfer、occupancy IoU；
- 多视角：novel-view consistency、重投影误差、跨 camera identity；
- 动态：scene flow、对象轨迹、future occupancy；
- 决策：碰撞预测、可达性、空间任务成功；
- 成本：地图内存、更新频率、渲染/rollout 时延。

## 7. 典型创新

- 3D 输入：更可靠的空间感知；
- 3D 监督：把几何作为辅助约束；
- 3D 隐状态：让 dynamics 和 memory 共享坐标；
- 3D 输出：让外部 planner/renderer 消费结构；
- 4D 动态：显式建模运动实体与时变场景。

## 8. 边界与失败模式

- 高质量 3DGS 渲染不代表 collision mesh、尺度、质量或摩擦正确；
- 动态对象污染静态地图会导致 tracking 和 memory 一并退化；
- 稀疏观测下的不可见背面、透明/反光物体仍难；
- 3D token 数、内存和多视角训练成本可能抵消规划收益。
