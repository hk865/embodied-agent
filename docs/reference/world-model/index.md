# 世界模型工程手册

这里的“世界模型”不是一个单一架构名，而是一类围绕**状态、转移、条件干预和决策用途**组织的模型。文档按研究员进入领域时真正需要做的判断来组织，而不是按论文发表顺序堆叠。

## 文档结构

```text
基础：定义、任务、数据、Base/Baseline、训练、评测
表示轴：像素/视频、JEPA/潜空间、对象状态、3D/4D
动作轴：前向动作条件、逆动力学、WAM、规划搜索
横切：记忆、物理一致性、数据引擎、部署
系统：WM-VLA-WAM-SLAM、论文矩阵、研究问题
```

## 统一阅读约定

- **Base** 是预训练或初始化底座；**Baseline** 是可公平比较的完整实验系统。
- `z_t` 是模型内部状态，`o_t` 是观测，`a_t` 是动作，`c` 是语言/目标/任务条件。
- 任何路线均用同一检查顺序：任务 → I/O → 数据 → Base/Baseline → 训练与损失 → 推理 → 评测 → 失败模式。
- “模型宣称的能力”与“已经被何种实验支持的能力”分开记录。
