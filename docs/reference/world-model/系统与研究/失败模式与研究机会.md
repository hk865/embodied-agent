# 失败模式与研究机会

## 1. 全体系问题清单

| 来源模块 | 失败模式 | 为什么重要 | 研究机会 |
|---|---|---|---|
| 定义 | 名称膨胀 | 无法比较能力主张 | 能力卡、层级和反事实协议 |
| 任务/I-O | 动作/坐标不同步 | 学到错误因果 | 统一 action schema 与自动校验 |
| 数据 | 只有成功示范 | 不会预测失败和恢复 | 失败采集、主动数据和风险覆盖 |
| 表示 | 像素或 latent 各自偏置 | 外观/可控性难兼得 | 混合结构—生成表示 |
| 3D | 几何与物理脱节 | 不能直接规划接触 | 可计算几何、材料与 dynamics 对齐 |
| 记忆 | 幻觉长期化 | 错误会反复驱动决策 | 有来源/置信度的可撤销记忆 |
| 训练 | 预测损失压制动作 | WAM 变成 VLA 正则 | 梯度平衡、分阶段和因果消融 |
| 评测 | 视频分数替代能力 | 研究方向被错误优化 | 分层证据和闭环相关性 |
| 规划 | model exploitation | 模型内成功、真实失败 | uncertainty、保守搜索、真实校准 |
| 部署 | 世界模型过慢 | 决策错过时机 | event-triggered compute、蒸馏与分层控制 |

## 2. 优先研究问题

### 2.1 结构化输入输出

将动作、对象、相机、地图、记忆和任务进度从无结构 token 流中显式暴露，同时不牺牲视频 Base 的开放世界先验。关键不是“更多 JSON”，而是让训练、推理和评测共享同一可执行语义。

### 2.2 长时事实与可纠错记忆

研究“何时写入什么、以何种坐标索引、何时相信新观测、如何撤销错误”。指标应以重访、任务进度和错误恢复衡量，而非纯 context 长度。

### 2.3 3D/4D 如何进入 dynamics

深度 head、3DGS、occupancy 和对象图分别放在输入、监督、状态、输出和记忆中时，带来的是不同任务。下一步需要同 Base、同数据、同预算的系统比较，而不是更多视觉 demo。

### 2.4 可校准的动作因果

互联网视频提供观察先验，具身数据提供干预；如何用少量真实 `(o,a,o')` 数据把 latent action 对齐到精确控制，同时知道“自己不知道”，仍是关键问题。

### 2.5 有效的 sim-real 评测

仿真不必完全复刻真实成功率，但应保留策略排序、失败边界和改动方向。建立跨场景、跨 embodiment 的 ranking correlation 是比单次 sim-to-real demo 更有价值的目标。

## 3. 开题前自检

- [ ] 我的能力主张属于 L0—L5 哪一级？
- [ ] 新方法相对的完整 Baseline 是什么？
- [ ] 数据是否包含能区分相关与因果的干预？
- [ ] 3D、记忆或视频分支实际改变了哪个系统接口？
- [ ] 预测提升是否传导到规划或闭环收益？
- [ ] 最大失败样例是什么，谁能复现？

## 4. 结论

领域的下一步不是单纯生成更长、更清晰的视频，而是将可控状态、几何、记忆、不确定性、动作接口和可信评测连接起来。能够把这些接口做成标准工程闭环的系统，才会把“世界模型”从论文标签变成可用基础设施。
