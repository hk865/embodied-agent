# 长序列事实保持与记忆

## 1. 问题定义

长序列不是“把 context window 加长”。真正的问题是：对象、布局、任务进度和已发生事件如何在离开视野后保持，如何在新观测与旧事实冲突时校正。

将记忆写作：

\[
m_t=\operatorname{write}(m_{t-1},z_t,e_t),\qquad
\tilde m_t=\operatorname{retrieve}(m_t,q_t),\qquad
z_{t+1}=f(z_t,\tilde m_t,a_t)
\]

其中 `e_t` 是事件/新颖度/不确定性信号，`q_t` 是当前空间、对象或任务查询。

## 2. 记忆形式

| 形式 | 写入内容 | 优点 | 风险 |
|---|---|---|---|
| 滑动窗口 | 最近 token | 简单、无额外训练 | 长时必然遗忘 |
| KV cache / SSM | 压缩时序状态 | 速度好 | 难解释、错误难撤销 |
| 检索库 | 关键帧/latent | 可访问远历史 | 检索错配与延迟 |
| 对象表 | id、pose、属性、状态 | 事实可查、低带宽 | objectization 易错 |
| 空间地图 | occupancy/GS/mesh | 支持重访和几何查询 | 动态污染、内存大 |
| 事件日志 | 完成、失败、状态变更 | 支持任务进度 | 与视觉状态对齐难 |

## 3. 最小 Baseline

无记忆、固定滑窗、随机检索、时间最近检索、语义检索、几何检索、结构化对象/地图记忆。比较时固定总 token/内存预算，不可只给记忆模型更多上下文。

## 4. 训练目标

可加入重访一致性、对象状态恢复、memory retrieval contrastive 和不确定性：

\[
\mathcal L_{mem}=\mathcal L_{revisit}+\lambda_i\mathcal L_{identity}+\lambda_r\mathcal L_{retrieval}+\lambda_u\mathcal L_{uncertainty}
\]

最重要的是允许**修正和撤销**：记忆条目应带来源、时间、置信度、坐标和版本，避免模型把幻觉永久写入。

## 5. 评测协议

- 离开区域后重访：布局、对象身份、状态变化是否恢复；
- 遮挡后恢复：对象是否被错误复制、消失或替换；
- 长时任务进度：已完成步骤不会重复执行；
- 错误注入：错误记忆能否被新观测覆盖；
- 资源：命中率、误检率、平均检索时间、每秒内存和增长曲线。

## 6. 失败模式

- 把更长 token context 误称为事实记忆；
- 检索到外观相似但空间/时间错误的历史；
- 动态物体写入静态地图；
- 模型没有“未知”状态，错误事实被反复强化。
