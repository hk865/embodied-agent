# 物理、因果与空间一致性

## 1. 三种一致性不能混为一谈

| 一致性 | 问题 | 例子 |
|---|---|---|
| 视觉时序一致性 | 相邻帧是否平滑 | 不闪烁、光照连续 |
| 空间/身份一致性 | 同一物体和布局是否跨视角保持 | 重访的杯子仍在原位置 |
| 物理/因果一致性 | 动作与接触是否导致合理状态变化 | 推杯子会移动，撞墙会停止 |

视觉一致性是必要条件，但远弱于物理一致性。

## 2. 物理能力的操作化

不要求模型显式学出牛顿方程，但应在任务范围内满足：对象持久性、尺度/遮挡、碰撞、支撑、接触、重力、速度方向、材料或约束的可预测后果。对随机未来还应给出可能性分布，而非编造唯一未来。

## 3. 数据与监督

- 真实视频：广泛外观和自然运动，但缺乏反事实与精确物理状态；
- 引擎数据：可获得 pose、contact、force、material、collision 与动作分支；
- 真实重建：用于校准视觉/几何，不应把渲染逼真当物理真值；
- 合成数据：可覆盖危险和稀有事件，但需真实交互验证。

## 4. 损失与结构

可使用 depth/flow/pose/occupancy、对象轨迹、contact label、多视角重投影、动力学残差或 rule violation 辅助目标。它们应约束任务相关变量，而不是以“加一个 physics loss”替代干预测试。

\[
\mathcal L_{cons}=\lambda_{mv}\mathcal L_{multiview}+\lambda_o\mathcal L_{object}+\lambda_c\mathcal L_{contact}+\lambda_f\mathcal L_{future}
\]

## 5. 评测设计

1. **配对干预**：固定初始状态，改变一个动作或物理因素。
2. **概念诊断**：分开测对象持久、摩擦、液体、支撑、弹性，不把多种规律混进单个视频。
3. **多视角重访**：检查对象身份、尺度和几何闭环。
4. **失败预测**：模型能否预测抓空、滑落、碰撞和不可达。
5. **闭环相关性**：模型得分提升是否提高真实任务成功或安全。

## 6. 常见错误

- 生成合理的火焰、水或阴影，不代表模型可用于接触规划；
- 用无动作视频评估“动作理解”；
- 使用从同一生成模型导出的 evaluator 形成自证循环；
- 只展示视觉轨迹，不报告状态误差和失败动作。

## 7. 研究机会

结构化 3D state 与生成视频 decoder 如何共享物理约束；稀有接触和软体数据如何采集；如何对不确定物理参数进行校准；如何把状态一致性转换为 planner 可用的风险界限。
