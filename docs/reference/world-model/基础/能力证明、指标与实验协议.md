# 能力证明、指标与实验协议

## 1. 指标不是能力本身

同一 FVD/PSNR 可能来自不同机制：一个模型记住了视觉纹理，另一个模型学习了对象转移；二者对规划的价值完全不同。评测应对应明确能力主张，并至少含一个排除替代解释的对照。

## 2. 五层指标协议

| 层 | 能力主张 | 指标/实验 | 不能证明什么 |
|---|---|---|---|
| 视觉 | 图像像真、时序流畅 | FVD、LPIPS、PSNR、SSIM、人评 | 物理与动作因果 |
| 预测 | 未来误差低且可校准 | NLL、feature error、CRPS、calibration | 空间身份保持 |
| 结构 | 对象和几何不漂 | depth/pose、occupancy IoU、ID consistency、revisit | 规划一定成功 |
| 因果 | 动作结果正确 | paired action、action shuffle、失败预测 | 长时真实部署 |
| 闭环 | 有真实决策价值 | success/safety、regret、sim-real rank correlation | 开放世界通用性 |

## 3. 最小实验协议

### 3.1 预测协议

- 在 episode、场景或对象级 holdout 上测试；
- 按 1、2、4、8、16… horizon 报告曲线；
- 分开 teacher-forcing 和 free-running；
- 随机未来需报告 sample diversity 与 calibration，而非只报平均 MSE。

### 3.2 动作因果协议

对每个初始状态构造至少两个可区分动作；报告输出是否沿预期方向变化。必须包含 action-off 和 action-shuffled 对照，并专门评估不成功的动作、碰撞、无效动作和恢复行为。

### 3.3 空间与记忆协议

测试遮挡、相机绕行、离开后重访、多视角同步和对象状态改变；按时间绘制身份/布局/几何漂移，不只展示成功样例。

### 3.4 规划协议

在同一控制频率和 wall-clock 下比较：直接策略、无世界模型策略、world model 单样本、world model 多样本搜索。报告任务成功、危险事件、计算成本和模型漏洞案例。

## 4. 建议结果表字段

```text
Task | representation | action condition | data version | horizon |
visual | structure | causal | planning | real closed-loop | latency | failure cases
```

## 5. 评测失效的信号

- 只报 FVD 或几张视频；
- 只有成功动作、没有失败和反事实；
- 只在同一场景随机帧 split 上评测；
- 模型内 reward 高但真实执行低；
- 没有 action-off、无记忆、无几何、无搜索等必要消融。

## 6. 外部基准的正确用法

VideoPhy 类基准可诊断物理常识，MIND 类基准可测记忆与动作控制；机器人基准可测成功率。但没有任何一个基准覆盖所有表示、动作和 embodiment。使用公共基准的同时，应保留针对自身 Task Card 的诊断集。

## 7. 检查清单

- [ ] 每个主张至少映射到一个指标和一个反证对照。
- [ ] 报告 ID、OOD、长 horizon、失败动作和真实/高保真闭环。
- [ ] 视觉、结构、因果、规划指标不混为单一总分。
- [ ] 发布评测脚本、seed、数据版本和运行预算。
