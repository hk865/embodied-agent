# 定义、边界与能力分级

## 1. 操作性定义

对于工程研究，建议用以下检验句定义世界模型：

> 给定历史观测和可选动作/条件，模型是否维护一个足以预测任务相关未来的状态，并且在需要时能让不同干预产生不同、可评估的 rollout？

这一定义有意保留不同表示：状态不要求是符号对象，也可以是 latent token 或 4D 场；但必须说明它对什么未来“充分”。

\[
p(o_{t+1:t+H},r_{t:t+H}\mid h_t,a_{t:t+H})
\approx
p(o_{t+1:t+H},r_{t:t+H}\mid z_t,a_{t:t+H})
\]

其中 `h_t=(o≤t,a<t,c)`。若 `z_t` 不能支持该近似，模型只是压缩器或生成器，不是本任务下有效的世界状态。

## 2. 宽定义与严格定义

| 用法 | 可以称为 WM 的对象 | 文档中应额外说明 |
|---|---|---|
| 宽定义 / 产业语境 | 可重建、生成、编辑、探索 3D 世界的系统 | 其输出是 renderer、simulator 还是 planner |
| 预测定义 | 从历史预测未来观测或 embedding 的模型 | 是否有动作，是否能自由 rollout |
| 控制定 义 | 学习 `p(z'|z,a)` 并供规划使用的模型 | 状态、动作、奖励和不确定性接口 |
| 严格具身定义 | 可在真实/高保真模拟环境中支持干预和闭环决策的模型 | 反事实、失败、O​​OD 和闭环证据 |

不要通过名称裁决，而通过任务卡、反事实实验和下游用途裁决。

## 3. 三个思辨验证

### 3.1 动作打乱测试

保持历史和文本不变，替换为互斥动作。若预测未来几乎不变，模型没有可靠的动作因果接口；它可仍是观察预测器，但不应以动作世界模型宣传。

### 3.2 重访测试

让智能体离开一个区域后返回。若对象身份、布局、状态变化无法恢复，则长上下文不等于长期事实记忆。

### 3.3 规划增益测试

比较：直接策略、无世界模型辅助策略、同预算的模型内搜索。只有后者稳定优于前两者，才能声称世界模型的 rollout 对决策有净价值。

## 4. 能力卡模板

```yaml
claim: action-conditioned 3D latent world model
level: L3
state: object slots + camera-aligned occupancy
intervention: end-effector delta pose at 10Hz
horizon: 16 steps / 1.6s
known: rigid tabletop objects
unknown: cloth, contact force, occluded object identity
evidence:
  - paired action counterfactual
  - object/pose error by horizon
  - MPC versus direct policy
```

## 5. 典型边界

- **静态 3D 资产生成**：通常是空间世界构建，不自动具备时间动力学。
- **视频编辑**：通常是控制性渲染或数据增强；编辑若没有状态保持和动作语义，不等于模拟。
- **VLA**：直接预测动作的策略；除非明确预测未来状态或使用模型内 rollout，否则不因“具身”自动变成 WM。
- **动态 SLAM**：能建立动态语义地图，但若只估计当前状态或短轨迹，仍主要是状态估计器。

## 6. 项目验收清单

- [ ] 明确模型达到 L0—L5 中的哪一级。
- [ ] 明确哪些状态因素是预测目标，哪些被允许忽略。
- [ ] 说明动作、语言和相机运动的干预语义。
- [ ] 至少有一个反事实或动作打乱实验。
- [ ] 不用视觉质量指标单独证明物理或规划能力。
