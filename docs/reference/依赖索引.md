# 第三方工程与大型资产索引

本仓库只管理 Agent 研究、协议、集成代码和辅助文档。下列工程不复制进仓库，应在实现阶段通过已锁定 commit 的安装脚本、submodule 或容器镜像引入。

| 能力 | 上游/基线 | 用途 | 入库规则 |
|---|---|---|---|
| Go2 RL 运动控制 | [Unitree RL Lab](https://github.com/unitreerobotics/unitree_rl_lab) | Isaac Lab + RSL-RL 训练、ONNX 导出 | 只提交本项目的配置、评估和适配层 |
| 机器人资产 | [unitree_ros](https://github.com/unitreerobotics/unitree_ros) | Go2 URDF 与 mesh | 远程按版本下载，不复制 mesh |
| Sim2Sim | [unitree_mujoco](https://github.com/unitreerobotics/unitree_mujoco) | 策略跨仿真器验证 | 固定 commit，不提交仿真资产和构建产物 |
| 局部规划 | [SCAN-Planner](https://github.com/wuyi2121/SCAN-Planner) 及本地 ROS 2 移植 | 局部路径和 B-spline 轨迹 | 移植使用独立 fork，本仓库只保存 adapter |
| 定位建图 | FAST-LIVO2 | LiDAR-视觉-惯性里程计与几何地图 | 作为外部 ROS 2 依赖，不复制数据集、rosbag 和点云 |
| 通用 VLA | OpenVLA / π0 / SmolVLA 等 | 冻结的局部操作执行器 | 权重使用对象存储或模型仓库，Git 只保存配置和 hash |

## 不进入主仓库的内容

- 模型权重、checkpoint、ONNX 迭代产物；
- rosbag、点云、视频、地图、仿真资产和数据集；
- `build/`、`install/`、`log/`、W&B 运行记录；
- 上游工程的整包拷贝、嵌套 `.git/` 和下载压缩包；
- 真实机器人网络参数、API key、token 和未脱敏 trace。
