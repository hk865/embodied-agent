# 运动控制（Motion Control）
> 核心职责：接收规划层输出的参考轨迹/目标点，**驱动机器人趋近目标**，输出执行器指令（力矩/速度/位置）。

---

## 1. 经典控制

### 1.1 PID 控制
> 最基础、最广泛使用的反馈控制器。

**三个分量**
- **P (Proportional)**：比例项，消除当前误差 — 快速响应但有余差
- **I (Integral)**：积分项，消除累积误差 — 消余差但可能积分饱和（windup）
- **D (Derivative)**：微分项，预测误差趋势 — 抑制振荡但放大噪声

**变体和技巧**
- 串联 PID（Cascaded PID）— 外环位置→内环速度→最内环力矩，逐层控制
- 前馈控制（Feedforward）— 结合动力学模型，PID 只补误差
- 抗积分饱和（Anti-windup）— Clamping / Back-calculation
- 死区（Deadband）— 小误差不响应，防震荡
- 增益调度（Gain Scheduling）— 不同工况用不同参数

**典型应用**
- 直流电机速度/位置控制
- 无人机姿态控制（内环角速度 PID）

### 1.2 LQR（线性二次型调节器）
> 基于最优控制理论的线性状态反馈控制。

**核心概念**
- 状态空间模型：x_dot = Ax + Bu
- 代价函数：J = ∫(x^T Q x + u^T R u) dt
- 最优增益 K = R^(-1) B^T P，P 由 Riccati 方程解得
- Q 矩阵权重 → 状态跟踪精度
- R 矩阵权重 → 控制能量消耗

**变体**
- LQI（LQR + 积分项）：消除稳态误差
- TV-LQR（时变 LQR）：沿轨迹线性化
- iLQR（迭代 LQR）：非线性系统迭代求解

**典型应用**
- 倒立摆平衡
- 四旋翼悬停
- 平衡车（Segway）

### 1.3 经典控制小结
| 方法 | 优点 | 缺点 |
|------|------|------|
| PID | 简单、无需模型、调参直观 | 多变量耦合难处理、性能有限 |
| LQR | 最优、解析解、多变量自然处理 | 需线性模型、需全状态可测 |

## 2. 现代与进阶控制

### 2.1 MPC（模型预测控制）
> 在有限时域内在线求解优化问题，滚动优化<预测+执行>。

**核心思想**
- 预测模型 → 描述系统未来行为
- 滚动优化 → 每个控制周期求解优化问题
- 反馈校正 → 每次只执行第一步，下一周期重新求解

**与规划层 MPC 的关系**
- 规划层 MPC：输出**参考轨迹**（低频，~10 Hz）
- 控制层 MPC：输出**执行器指令**（高频，~50-200 Hz）

**关键要素**
- 预测时域（N）— 步数，越长越优但计算量越大
- 控制时域（M ≤ N）— 通常 M ≪ N
- 代价函数 — 跟踪误差 + 控制增量 + 终端代价
- 约束 — 执行器限幅、状态约束、安全约束

**求解方法**
- 线性 MPC → QP（二次规划）→ OSQP / qpOASES
- 非线性 MPC（NMPC）→ NLP → IPOPT / acados / CasADi
- 显式 MPC → 离线计算分段仿射控制律

**典型应用**
- 自动驾驶轨迹跟踪
- 四旋翼轨迹跟踪（aggressive maneuvers）
- 机器人全身运动控制

### 2.2 WBC（全身控制 / Whole-Body Control）
> 同时协调多个任务（站立、抓取、防摔），在多约束下求解关节力矩。

**核心思想**
- 任务分层：高优先级任务（保持平衡）不被低优先级任务（抓取）干扰
- 零空间投影（Null-space Projection）：低优先级任务在高优先级任务的零空间中执行
- 往往基于 QP（二次规划）求解

**数学框架**
- 任务空间动力学映射：J q_ddot + J_dot q_dot = x_ddot_desired
- 多任务 QP：
  ```
  min Σ w_i ||J_i q_ddot + J_i_dot q_dot - x_i_desired||²
  s.t. 浮动基座动力学、接触约束、力矩限制、摩擦锥
  ```

**常用框架**
- Tsid (Pinocchio-based)
- Drake (MIT/Toyota)
- OC-Software (IHMC)

**典型应用**
- 人形机器人（Atlas, Digit）
- 四足机器人站立操作
- 多接触点场景（手抓+脚立）

### 2.3 滑模控制（SMC）
> 通过设计滑模面与切换控制律，迫使系统状态沿预定"滑模面"运动，对匹配的模型不确定性和外部扰动具有完全鲁棒性。

**核心思想**
- 滑模面设计：s(x) = 0，定义期望的动态行为（如 s = e_dot + λe）
- 到达阶段 → 滑模阶段：状态从任意初始点趋近滑模面，然后沿滑模面滑向平衡点
- 切换控制律：u = u_eq + u_sw，等价控制 + 切换控制
  - u_eq（等价控制）：令 s_dot = 0，维持理想滑模运动
  - u_sw（切换控制）：η·sign(s) 或 η·sat(s/φ)，克服不确定性

**抖振（Chattering）问题与对策**
- 根源：理想切换 sign(s) 引起高频切换，激发未建模动态
- 缓解方法：
  - 边界层法：用 sat(s/φ) 替代 sign(s)，在边界层内连续化
  - 高阶滑模（HOSM）：对 s 的高阶导数施加切换，如 Super-twisting 算法
  - 扰动观测器 + SMC：用观测器估计扰动并前馈补偿，减小切换增益 η

**典型应用**
- 电机伺服控制（高精度位置跟踪）
- 机械臂轨迹跟踪（关节空间/任务空间）
- 电力电子变换器（DC-DC, AC-DC）

### 2.4 自适应控制
> 系统参数未知或缓慢变化时，在线估计参数并自动调整控制律，使系统在不确定条件下保持期望性能。

**主要范式**
- **MRAC（模型参考自适应控制）**
  - 设置参考模型表征期望闭环动态
  - 自适应律（基于 Lyapunov 或 MIT 规则）调整控制器参数，使实际输出跟踪参考模型输出
  - 关键：自适应律需保证参数收敛与系统稳定
- **STR（自校正调节器）**
  - 在线辨识系统参数（如 RLS 递推最小二乘）
  - 基于当前参数估计，实时求解控制律（如极点配置、最小方差）
  - 隐含"确定性等价原理"：将估计参数当作真实值使用
- **自适应鲁棒控制（ARC）**
  - 结合自适应参数估计 + 确定性鲁棒控制
  - 参数估计处理结构化不确定性，鲁棒项压制非结构化扰动
  - 参数估计投影保证有界性

**典型应用**
- 负载变化场景（机器人末端抓取不同质量物体）
- 气动/液压系统（参数随温度、压力漂移）
- 飞行器（质量、气动参数变化）

### 2.5 鲁棒控制（H∞, μ-synthesis）
> 在频域或状态空间框架下，将不确定性和性能指标形式化为系统范数约束，设计控制器在"最坏情况"下仍满足性能要求。

**H∞ 控制**
- 核心问题：minimize ||T_zw||∞，即从扰动 w 到性能输出 z 的传递函数 H∞ 范数最小化
- 典型框架：混合灵敏度 S/KS/T 加权
  - S（灵敏度函数）：扰动抑制 + 跟踪性能
  - KS（控制灵敏度）：控制能量约束
  - T（补灵敏度）：鲁棒稳定性 + 噪声抑制
- 频域整形：通过加权函数 W₁, W₂, W₃ 在不同频段分配性能要求
- 求解：DGKF 方法将 H∞ 问题转化为两个 Riccati 方程 / LMI 求解

**μ-synthesis（结构奇异值综合）**
- 动机：H∞ 对所有不确定性一视同仁，保守性大
- μ-synthesis 利用不确定性的结构化信息（如对角块结构），降低保守性
- 通过 D-K 迭代交替求解 H∞ 控制器和 D-scaling，逼近 μ 上界
- 代价：控制器阶数极高，需模型降阶

**典型应用**
- 柔性结构振动抑制（模态不确定性大）
- 光盘/硬盘驱动器伺服（高频扰动抑制）
- 飞行控制系统

### 2.6 ADRC（自抗扰控制）
> 韩京清提出，核心思想：将系统所有不确定因素（内部未建模动态 + 外部扰动）统一视为"总扰动"，由扩张状态观测器实时估计并前馈补偿，使系统简化为积分器串联型。

**三个核心组件**
- **TD（跟踪微分器）**：从参考信号提取光滑的跟踪信号及其微分，实现过渡过程安排，避免超调与冲击
- **ESO（扩张状态观测器）**：将"总扰动"扩展为系统额外状态，仅用输入输出信息实时估计所有状态 + 总扰动
  - 这是 ADRC 的灵魂 — 无需精确模型，只需知道系统阶次和控制增益粗略值
- **NLSEF（非线性状态误差反馈）** / **LSEF（线性）**：基于 ESO 估计的状态误差 + 扰动补偿生成控制量
  - 线性 ADRC（LADRC）：带宽参数化，整简化为 ω_c（控制器带宽）和 ω_o（观测器带宽）两个参数

**ADRC vs PID**
| 维度 | PID | ADRC |
|------|-----|------|
| 微分获取 | 直接差分，噪声放大 | TD 跟踪微分，噪声抑制 |
| 扰动处理 | 积分滞后补偿 | ESO 实时估计 + 前馈补偿 |
| 调参 | Kp, Ki, Kd 三参数 | 带宽参数化，物理意义明确 |
| 模型依赖 | 无模型 | 仅需阶次和近似增益 |

**典型应用**
- 电机伺服控制（替代传统 PID 串级）
- 电力系统频率调节
- 无人机姿态控制

### 2.7 RL-based 控制（强化学习控制）
> 基于深度强化学习的运动控制，属于完全不同的范式：从"分析建模→设计控制器"转变为"定义奖励→训练策略"。详见 **第 3 节**。

### 2.8 进阶方法对比
| 方法 | 模型依赖 | 鲁棒性 | 计算复杂度 | 调参难度 | 适用场景 |
|------|----------|--------|-----------|---------|---------|
| 滑模控制（SMC） | 低（需误差动态） | 极高（对匹配扰动免疫） | 低 | 中（抖振-鲁棒权衡） | 高精度伺服、电力电子 |
| 自适应控制 | 中（需结构已知） | 中（参数不确定） | 中 | 中（自适应律设计） | 参数时变系统 |
| 鲁棒控制（H∞） | 高（需不确定性上界） | 极高（最坏情况保证） | 离线高一在线低 | 高（加权函数整定） | 航空航天、精密伺服 |
| ADRC | 低（仅需阶次+增益） | 高（总扰动补偿） | 低-中 | 低（带宽参数化） | PID 升级替代通用场景 |

## 3. 深度学习与强化学习控制

> 一种完全不同的范式：不再手工设计控制律，而是**定义目标（奖励函数）→ 让策略网络在仿真中试错学习**。核心优势在于免于精确动力学建模 — 这对足式机器人（多接触、欠驱动、强非线性）尤为重要。

### 3.1 为什么 RL 能在运动控制中成功？

传统控制（PID / MPC / WBC）依赖精确的动力学模型，而足式机器人的足-地接触是离散、摩擦不确定的强非线性过程，精确建模极其困难。RL 绕过了这一问题：

| 挑战 | 传统方法 | RL 方法 |
|------|---------|---------|
| 足-地接触建模 | 需精确摩擦锥/接触模型 | 仿真中自然交互，策略隐式学习接触规律 |
| 高维耦合 | 依赖模型简化与解耦 | 神经网络天然处理高维输入 |
| 环境适应性 | 需显式设计鲁棒策略 | 域随机化训练，泛化到未见地形 |
| 步态生成 | 基于 ZMP / SLIP 等简化模型规划 | 端到端涌现自然步态（trot, pace, gallop...） |
| 开发周期 | 手工建模+调参，数周~数月 | 大规模并行仿真训练，数小时~数天 |

### 3.2 案例：Unitree Go2 的 RL 步态训练

Unitree Go2 是典型的 RL-driven 四足机器人，其步态策略完全由强化学习训练得到。以下为其背后的典型训练管线：

```
┌─────────────────────────────────────────────────────────────────┐
│                    RL 训练管线（以 Go2 为例）                      │
├───────────┬───────────┬───────────┬───────────┬─────────────────┤
│ 仿真环境   │  奖励设计  │  训练算法  │  Sim2Real  │  部署推理        │
│ Isaac Gym │ 速度跟踪   │  PPO      │  域随机化  │  策略网络→力矩   │
│ 并行数千  │ 能耗惩罚   │  GAE      │  教师-学生 │  关节 PD 底层    │
│ 环境实例  │ 平衡保持   │  价值裁剪  │  实机微调  │                  │
└───────────┴───────────┴───────────┴───────────┴─────────────────┘
```

**核心设计要点**：

- **观测（Observation）**：IMU（角速度、重力方向）、关节位置/速度、上一帧动作、用户速度指令（v_x, v_y, ω_z），共 ~48 维
- **动作（Action）**：12 个关节的目标位置（PD 底层跟踪），~12 维
- **奖励（Reward）**：
  - 主项：速度跟踪误差（鼓励跟随指令）、能耗（力矩 × 速度，惩罚过度用力）
  - 辅助项：躯干高度/姿态保持、足底离地高度（防拖地）、关节加速度惩罚（平滑性）
  - 终止惩罚：躯干触地或关节超限 → episode 终止
- **网络结构**：MLP（3~4 层，每层 256~512 单元），ELU/Tanh 激活
- **控制频率**：50 Hz（策略推理）→ 200 Hz（PD 底层插值）

### 3.3 RL 核心算法与训练稳定性

**PPO（Proximal Policy Optimization）**— 足式机器人 RL 的事实标准：

- **Clipped Surrogate Objective**：
  ```
  L_CLIP = E[min(r_t(θ)·A_t, clip(r_t(θ), 1-ε, 1+ε)·A_t)]
  ```
  核心思想：限制新旧策略比率 r_t(θ) 的变化幅度（通常 ε=0.2），防止单步更新过大导致策略崩溃。

- **GAE（Generalized Advantage Estimation）**：在 bias-variance 之间折中估计优势函数 A_t，λ 参数控制折中程度（λ=0.95 常用）。

- **价值函数 Clipping**：对 V(s) 的更新也做裁剪，防止价值估计突变。

**SAC（Soft Actor-Critic）**— 最大熵 RL，探索能力更强：

- 在目标中增加策略熵项：`J = Σ[γ^t(r + α·H(π(·|s)))]`
- 自动温度参数 α 调节探索 vs 利用权衡
- 适合需要丰富探索的任务（如复杂地形步态、灵巧操作）

**训练稳定性关键技术**：

| 技术 | 作用 | 具体做法 |
|------|------|---------|
| 奖励塑形（Reward Shaping） | 提供稠密学习信号 | 将稀疏目标分解为逐步可衡量的小奖励 |
| 课程学习（Curriculum） | 渐进式难度提升 | 地形从平坦→台阶→楼梯→碎石逐步升级 |
| 域随机化时机 | 避免训练初期崩溃 | 训练前 20% 步数无随机化，稳定后再引入 |
| 对称性正则化 | 利用机器人对称先验 | 对观测/奖励施加左右对称约束 |
| Early Termination | 避免无效探索 | 摔倒/关节超限立即终止，不浪费计算 |
| 多轮 Fine-tuning | 渐进改良 | 训练→部署→采集真实数据→继续训练 |

### 3.4 教师-学生蒸馏

> 核心矛盾：仿真中可获取任意"特权信息"（地面摩擦系数、地形高度图、精确接触力），但真实机器人只有本体传感器（IMU + 关节编码器）。

**两级训练架构**：

```
┌──────────────────┐        ┌──────────────────┐
│   Teacher 策略    │        │   Student 策略    │
│  （仿真特权信息）  │ ─蒸馏→ │  （仅本体传感）    │
├──────────────────┤        ├──────────────────┤
│ 输入：            │        │ 输入：            │
│  · IMU           │        │  · IMU           │
│  · 关节编码器     │        │  · 关节编码器     │
│  · 指令速度       │        │  · 指令速度       │
│  · 地形高度图 ★   │        │  · 历史观测窗口   │
│  · 摩擦系数 ★     │        │  （隐式推断地形）  │
│  · 接触力 ★       │        │                  │
│  输出：关节目标    │        │  输出：关节目标    │
└──────────────────┘        └──────────────────┘
```

**蒸馏流程**：
1. **训练 Teacher**：在仿真中用特权信息充分训练，获得高性能策略
2. **收集数据**：Teacher 在多样化环境中 rollout，记录 (obs_privileged, obs_proprio, action)
3. **训练 Student**：仅用本体传感器观测，通过监督学习模仿 Teacher 动作：
   ```
   L_distill = MSE(a_student, a_teacher) + λ·KL(π_student || π_teacher)
   ```
4. **RL 微调 Student**：蒸馏后再进行少量 RL 训练，让 Student 在真实观测空间下补充优化

**Go2 的实践**：Teacher 包含地形扫描信息（通过仿真中的高度采样），Student 仅靠 IMU + 关节历史隐式推断地形特征，蒸馏后 Student 在盲爬楼梯等地形上仍表现良好。

### 3.5 Sim2Real 转移与实机微调

**域随机化（Domain Randomization）**— 缩小 Sim2Real gap 的核心手段：

| 随机化项 | 范围 | 目的 |
|---------|------|------|
| 地面摩擦系数 | 0.3 ~ 1.5 | 适应不同地面材质 |
| 地面恢复系数 | 0.0 ~ 0.8 | 适应软硬地面 |
| 机器人质量/惯量 | ±20% 标称值 | 适应建模误差 |
| 电机力矩延迟 | 0 ~ 20 ms | 模拟通信延迟 |
| 关节摩擦/阻尼 | 随机偏置 | 模拟机构磨损 |
| 外部推力扰动 | 随机施加 | 增强抗扰能力 |
| IMU 噪声/偏置 | 高斯噪声 | 适应真实传感器 |

**实机微调（Real-world Fine-tuning）**：
- 仿真训练得到的策略在真实机器人上运行时，通常性能会有一定下降（如跟踪精度降低 10~30%）
- **在线微调**：直接在真实机器人上继续 RL 训练（需小心安全约束），用于小幅度性能补救
- **系统辨识 + 重训练**：先采集少量真实数据做系统辨识 → 修正仿真模型参数 → 再在修正后的仿真中重训练
- **Offline RL 微调**：将实机运行数据收集为 dataset，在离线模式下微调策略，规避在线探索风险

### 3.6 仿真环境与训练基础设施

**主流仿真平台**：

| 平台 | 特点 | 适用场景 |
|------|------|---------|
| **Isaac Gym** (NVIDIA) | GPU 并行数千环境，速度快 | 大规模 RL 训练首选（Go2 级机器人训练仅需数小时） |
| **Isaac Sim** (NVIDIA) | 高保真渲染+物理，ROS2 集成 | 需要视觉传感器 / 更真实物理时 |
| **MuJoCo** (Google DeepMind) | 开源、轻量、精确接触动力学 | 学术研究、快速原型 |
| **RAISIM** | 专为足式机器人优化 | 多刚体接触仿真，速度快 |

**典型训练规模（以 Go2 级别为例）**：
- 并行环境数：4096
- 单环境步长：0.02 s（50 Hz 控制）
- 总训练步数：~1~2 亿步（约 30 分钟 ~ 2 小时，视 GPU）
- GPU：单张 RTX 4090 / A6000
- 策略推理延迟：< 1 ms（MLP 前向），满足 50 Hz 实时要求

**奖励函数设计的经验法则**：
1. **生存优先**：先确保不倒，再加运动目标
2. **惩罚要软（soft penalty）**：避免阶梯式奖惩，用连续/二次型惩罚
3. **尺度归一化**：不同奖励项量级相近（通常各自归一化到 [0, 1] 或 [-1, 0]）
4. **权重迭代调优**：先大权重保稳定性，再逐步调整任务权重

## 4. 执行器与底层驱动

### 4.1 执行器类型
- 直流无刷电机（BLDC）— 机器人主流
- 步进电机 — 开环位置控制
- 舵机 — 位置伺服，娱乐/教育机器人
- 液压/气动 — 大功率场景（如 Atlas 初期）

### 4.2 控制环路层级
```
位置指令 → 速度环 → 电流/力矩环(FOC) → PWM → 电机
    ↑                    ↑
  位置反馈           电流反馈
```
- 力矩控制（Torque Control）→ 直接力控
- 阻抗控制（Impedance Control）→ 力-位置柔性关系
- 导纳控制（Admittance Control）→ 位置-力柔性关系

## 6. 与规划控制的关系

```
        规划控制                          运动控制
   ┌──────────────┐                ┌──────────────┐
   │  目标 → 路径  │── reference ──→│  跟踪 → 执行  │── 力矩/速度 → 机器人
   │  (What to do) │                │ (How to do)  │
   └──────────────┘                └──────────────┘
     低频 (~10 Hz)                    高频 (~100-1000 Hz)
     空间路径/轨迹                    力/力矩/速度指令
     回答：怎么走？                    回答：怎么驱动机器？
```

**核心区别**
| 维度 | 规划控制 | 运动控制 |
|------|----------|----------|
| 输入 | 地图、任务目标 | 参考轨迹 + 当前状态 |
| 输出 | 路径/轨迹（setpoint） | 执行器指令（力矩/速度） |
| 频率 | 低频（~10Hz） | 高频（~100-1000Hz） |
| 模型 | 几何/运动学为主 | 动力学为主 |
| 精度要求 | 路径可行即可 | 实时精确跟踪 |

**桥接方式**
- 规划输出 trajectory（位置+速度+加速度+时间戳）
- 控制以其为 reference 进行追踪
- 常见组合：全局 A* + 局部 TEB + 底层 MPC/PID
