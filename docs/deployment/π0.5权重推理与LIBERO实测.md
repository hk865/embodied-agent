# π0.5 权重推理与 LIBERO 实测

2026 年 10 月 6 日，本机 RTX 5070 Ti 16 GB 已完成官方 `pi05_libero` 权重推理和 LIBERO 闭环仿真。`libero_spatial` 的 10 个任务各运行一次，全部成功，运行错误为 0。这个结果确认本机可以运行 π0.5 单环境仿真；每任务一次、固定 seed 和初始状态的小测试不能作为论文成功率复现。

## 模型和环境

使用 [openpi 官方源码](https://github.com/Physical-Intelligence/openpi/tree/215abfb217dbac7d5f1273282331b9b1866c0479)的 `pi05_libero` 配置与 `gs://openpi-assets/checkpoints/pi05_libero`，没有混用 RLinf 的 SFT 权重。原始检查点和 tokenizer 均保存官方 generation、CRC32C、可用 MD5 及本地 SHA256。

模型环境为 Python 3.11.17、Torch 2.7.1 cu128、Transformers 4.53.2、CPU JAX 0.5.3。显卡实际通过 BF16 矩阵运算，Torch 包含 `sm_120`。依照官方 PyTorch 路线，五个 Transformers 替换文件只安装到独立 server 环境；文件哈希已核对，未修改上游源码。

仿真使用独立 Python 3.11.15 client 环境、MuJoCo 3.2.3、robosuite 1.4.1、NumPy 1.26.4 和 CPU Torch 2.5.1。LIBERO 源码固定为 `f78abd68ee283de9f9be3c8f7e2a9ad60246e95c`。配置、缓存和资产放在本工作区，没有写入用户默认 LIBERO 配置。

本次安装的是推理与转换所需依赖子集，LeRobot 使用 openpi 锁定的 `0cf864870cf29f4738d3ade893e6fd13fbd7cdb5` 源码。精确包版本见 [server 快照](../../workspace/vla_baselines/configs/pi05-server.versions.json)和 [client 快照](../../workspace/vla_baselines/configs/pi05-client.versions.json)，不应直接用作训练环境。

## 转换与评测范围

[转换脚本](../../scripts/vla/convert_pi05.py)调用官方参数映射，补齐原检查点 `assets` 的复制。所有推理所需参数完整，额外映射键为 0。两个未直接映射的语言输出头分别为已加载词嵌入的共享权重、动作采样不使用的 expert 输出头。Torch 总计 3,616,757,520 个参数，其中未使用的 expert 输出头占 263,323,648 个；不能把该总量直接对应成论文的模型规模。

采用官方选择性 BF16 推理，关闭 `torch.compile`。没有进行 JAX 与 PyTorch 的数值对照，当前证据是来源、参数覆盖、输出有效性和小规模任务结果。

评测为 `libero_spatial` task 0–9、每任务 1 次、seed 7、各任务官方初始状态 index 0。相机渲染 256，输入按官方方式旋转 180 度并缩放至 224；输入状态 8 维、动作 7 维，预测 10 步、每 5 步重新请求，等待 10 步稳定，策略步上限 220。成功必须由环境任务完成判定返回 `done`；通信、动作、渲染或视频错误单独计为运行错误。

本次单 trial 与官方环境创建方式一致。当前小评测脚本在多 trial 时每次新建并重新 seed 环境，而官方脚本每任务只创建并 seed 一次；正式多 trial 评测需先统一此行为，并扩展任务套件和初始状态。

## 本机再次运行

在 `embodied-agent` 项目根目录，先在一个终端启动模型服务：

```bash
env -u PYTHONPATH -u PYTHONHOME PYTHONDONTWRITEBYTECODE=1 OMP_NUM_THREADS=8 \
  workspace/vla_baselines/.venvs/pi05-server/bin/python scripts/vla/run_pi05.py serve \
  --checkpoint workspace/vla_baselines/checkpoints/pi05_libero_pytorch \
  --output workspace/vla_baselines/artifacts/pi05-next-server.json
```

看到 `server listening on 127.0.0.1:8000` 后，在另一终端运行：

```bash
env -u PYTHONPATH -u PYTHONHOME PYTHONDONTWRITEBYTECODE=1 \
  workspace/vla_baselines/.venvs/pi05-client/bin/python scripts/vla/eval_pi05_libero.py \
  --task-ids all --trials 1 --seed 7
```

不指定 `--output-dir` 会创建新的结果目录。`--task-ids 0` 只测一个任务，`--suite libero_object/libero_goal/libero_10` 可选择其他套件；这些套件本次未测。结束后在模型终端按 Ctrl+C 释放显存。

仅测试权重推理可以将第一条命令的 `serve` 换成 `smoke` 并使用新的报告路径；推理结束后进程自动退出。权重及环境已留在本机，无需再次下载或转换。
