## 通用 Agent 自己承担运行时决策

Agent as Policy（AGP）把任务中的观察、几何计算、编程和调整都交给通用 Agent，不再必须调用专门训练的 VLA。它不意味着 LLM 直接按电机频率输出力矩：机器人桥接层仍处理相机、运动学、轨迹、限位和跟踪。（§3）

## 从目标视频到装配动作

论文先由准备 Agent 整理任务指令、目标图像/示范视频、接口文档、完成标准和预算，执行 Agent 再在工作目录中操作。以插接两个零件为例，它看参考材料和当前相机图像，读取腕部深度与相机标定，写代码估计位置及朝向，再发送末端位姿或关节目标。运动后读取误差、新图像和机器人状态，若插入未完成便调整对齐或抓取方式。

程序、图片和笔记留在工作区，使 Agent 可以重用几何估计与操作流程。机器人控制器通过 Mink 等逆运动学工具把末端目标转换为关节轨迹；Agent 思考期间控制器维持机器人状态。动态投掷另有带时序的运动程序接口，不是靠每个 LLM 请求实时决定释放瞬间。

## 冻结模型也依赖充分接口

执行阶段通用模型权重不变，也没有单独动作策略训练；但机器人模型、相机标定、低层运动控制和任务准备材料不可省略。RGB 和深度让它能测量现场；“零任务训练”不能理解成没有工具先验、没有说明文档或没有参考视频。

论文在真实 I2RT YAM 单/双臂上评估视频装配、目标图搭积木、翻骰子、投掷和折毛巾等任务。v3 主表是每配置 5 或 10 次的小样本，试验从预定义场景开始；部分任务平均耗时数十分钟，时间等指标多数只对成功试验统计，投掷另有口径。（§4、表 1）

## 能力与效率要一起看

这些实验表明通用 Agent 能在运行时构造有用的操作程序并恢复，但不证明它具有毫秒级反射，也不证明在未知工厂环境中普遍可靠。复杂软体与双臂协调仍有失败。保存程序可减少重复推理，但保存经验本身的时间也应计入成本。

对当前 RPent，可把它作为“无 VLA、同感知和控制预算”的概念对照；不能直接拿 AGP 真机成功率与 LIBERO-Pro 仿真做排名。更有用的问题是哪些接触阶段确实需要 VLA，哪些阶段可由观察加几何程序解决，以及去掉 VLA 后付出了多少推理时间。
